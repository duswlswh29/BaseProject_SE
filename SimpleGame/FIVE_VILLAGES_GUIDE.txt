5개 마을 확장

적용 대상: Village 모드. 별도 Level1 사냥터의 생성 규칙은 유지합니다.
마을: 윌로미어 / 솔바람 / 호수빛 / 돌나루 / 새벽숲.
각 마을 소속 주민 20명, 총 100명. 각 마을 주택 8채, 총 40채.
각 마을의 주민 2명은 전달자로 이웃 마을을 순차 방문합니다.
따라서 실제 현재 위치 기준 인원은 20명과 다를 수 있습니다.

이동과 맵
플레이 영역 X -30~190, Z -40~40 (220 x 80 단위).
마을 중심 X 0/40/80/120/160, Z 0.
연결 도로는 중심→Z -12 도로→이웃 마을 중심입니다.
인접 중심 간 도로 길이 64, 플레이어 속도 3.2단위/초로 약 20초.
직선 지름길은 더 빠르며 군중, 우회, 전투, 대화가 있으면 더 오래 걸립니다.
출발 마을의 기존 튜토리얼 및 완료 후 Level1 자동 이동은 유지합니다.
Tab으로 Village에 돌아오면 확장된 마을을 계속 탐험할 수 있습니다.

몬스터
4개 마을 사이 지형에 전체 100개 슬롯을 배치합니다.
처치 후 2초 뒤 이전 위치에서 10단위 이상, 플레이어에서 12단위 이상 떨어진
새 지점을 탐색합니다. 주민, 다른 몬스터, 도로, 마을 안전 영역, 장애물을 피합니다.
유효 지점이 없으면 0.5초 후 재시도합니다. 안전한 지점 없이 강제 생성하지 않습니다.

소문
5개 마을마다 한 주민이 자기 마을의 빛 목격 소문을 알고 시작합니다.
전역 자동 전파는 없습니다. NPC끼리 3단위 이내로 만나고,
둘 중 한 명이 마지막 수신 위치에서 0.25단위 이상 이동했을 때 교환합니다.
1초마다 처리하며 수신 결과는 동시 반영합니다. 같은 순간 여러 사람을 거쳐
먼 마을까지 소문이 순간 이동하는 연쇄 반영을 방지합니다.
전달자는 약 2.4단위/초로 도로를 이동하고 방문지에서 12초 머뭅니다.
마을에 속한 주민 수는 이동해도 바뀌지 않습니다.
NPC 일반 대화에서도 알고 있는 소문 한 가지를 표시합니다.
소문은 현재 실행 세션의 상태이며 R 초기화/게임 재시작 시 초기화됩니다.
비활성 지역은 업데이트되지 않으므로 Level1에 있는 동안 마을 소문도 멈춥니다.

모니터링 JSON schema_version 2
map_bounds: 실제 플레이 영역. HTML 위치도에서 사용합니다.
home_village: NPC 소속. region: 현재 위치에서 가장 가까운 마을의 관찰 구역.
rumor_mask: 비트 0~4가 각 출처 마을 소문을 의미합니다.
courier / destination_village: 전달자 여부와 방문 대상.
rumor_transfers_total: 새로운 지식이 생긴 NPC 접촉 쌍의 누적 수.
regions[].resident_count: 소속 인원 20.
regions[].npc_count: 현재 관찰 구역 인원 (마을 사이 이동자 포함).
regions[].rumor_informed_residents: 한 가지 이상 소문을 아는 소속 주민 수.
안전도 safety_score = max(0, 100 - 중심 반경22 안의 살아 있는 몹 수 * 6).
호기심 curiosity_score = 소속20명의 소문 보유 개수 합 / (20*5) * 100.
분위기 mood = 안전도55 미만이면 불안, 아니면 호기심40 이상이면 호기심,
그 외 평온. 실제 심리 시뮬레이션이 아니라 위 지표를 바탕으로 한 요약입니다.

검증
인접 마을 연결 도로 4개의 정적 장애물 샘플 2572개 검사 통과.
마을 주택 수 40개, 도로 이동시간 계산 20초 확인.
모니터 HTML의 JavaScript 문법 검사 통과.
게임 빌드/실행은 사용자 진행. 전달자 군중 회피와 리젠은 실제 실행 확인 필요.
