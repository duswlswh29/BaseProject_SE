윌로미어 튜토리얼 개선 내역

렌더링
- Renderer.cpp에 실제 렌더링 자원과 패스 관리 통합.
- 2048x2048 깊이 그림자 맵과 3x3 PCF 필터.
- HDR 장면 버퍼 -> 경계 완화, 빛 번짐, 톤 매핑, 색 보정, 비네트 -> 한글 UI 순서.
- 절차적 잔디, 돌 포장, 목재, 기와 텍스처와 밉맵.
- 박공지붕, 목조 프레임, 창틀, 밝은 창문, 문손잡이와 계단.
- 캐릭터 팔/다리/얼굴/의상/지팡이 분리 및 걷기 애니메이션.
  스프라이트 애니메이션이 아닌 분절된 3D 모델 애니메이션임.
- 호수 수면 변위, 물결 법선, 반짝임과 모닥불 불꽃/불티.

게임
- 맵 경계: X -28~28, Z -26~26. 이전 28x26에서 56x52로 면적 4배.
- 주민 6명에서 12명. 모두 한국어 이름과 대화.
- 주택 4채에서 8채, 야생동물 사슴/토끼/여우 총 12마리.
- 동물은 배회하며 플레이어 가까이에서 피함. 전투는 없음.
- 기존 퀘스트 목표 좌표는 유지하여 3~5분 튜토리얼 동선 보존.
- 한글 UI, 퀘스트, 대화, 완료 화면, 창 제목. Windows 맑은 고딕 사용.

구조
- TutorialLevel.h: 콜백 인터페이스
- TutorialLevel.cpp: 레벨, 입력, 퀘스트, 동물, 장면 구성
- Renderer.h/.cpp: 렌더링 패스, GPU 자원, 재질, 한국어 텍스트
- RenderShaders.h: 월드 및 후처리 GLSL
- SimpleGame.vcxproj 및 filters: 새 파일 등록, UTF-8/C++14/NOMINMAX 설정
- 외부 이미지 다운로드나 추가 라이브러리는 필요하지 않음.
- OpenGL 3.3 호환 프로필 사용. 기존 SolidRect 셰이더 파일은 보존하되 사용하지 않음.

확인한 내용
- 프로젝트 XML 파싱과 컴파일 대상 파일 존재 여부.
- 변경 파일 공백/패치 검사.
- 0.5 단위 격자 탐색으로 주민 12명과 퀘스트 목표의 접근 가능 여부.
- 동물 12마리의 초기 위치가 장애물 밖인지 확인.

빌드와 실제 화면 확인은 사용자 담당으로 실행하지 않았음.
실제 화질, 프레임률, 5분 이내 플레이 여부는 사용자 확인 필요.

권장 확인 순서
1. 기존 솔루션을 다시 열고 빌드. 새 TutorialLevel.cpp가 포함되는지 확인.
2. 한글 대화, 그림자, 돌길/기와/문 재질과 호수/불꽃 확인.
3. WASD 이동과 E/스페이스 퀘스트 완주.
4. 주변 지역에서 주민 12명과 사슴/토끼/여우 확인.
5. 창 크기 변경, ESC 정지/재개, R 초기화, 창 종료 확인.
