Willowmere Blender 에셋 통합

meshes.bin은 직접 제작한 Blender 원본에서 추출한 삼각형 메시입니다.
mesh_manifest.json에 각 모델의 원본 메시 이름과 범위를 기록했습니다.
Source/Willowmere_Modular_Library.blend에 모듈 메시와 골격, 모든 원본 Action이 있습니다.

적용
- 주인공: 마법학교 견습생 (7등신).
- NPC: 상인, 치유사/친절한 주민, 마법학교형의 역할별 모델.
- 공격형 몹: 야생 고양이와 늑대. 기존 몹의 전투 규칙/스탯은 유지.
- 평화 동물: 사슴, 작은 고양이, 늑대형. 기존 행동 규칙은 유지.
- 동행 생물: 작은 고양이형.
- 마을 집: 조립 예제 목조 주택. 기존 위치/충돌 영역에 맞춰 크기 조정.
- 주택 뒤: 탁자/통/상자. 출입구 옆: 등불.
- 자연물: 원본 침엽수/활엽수, 풀잎, 바위.
- 기존 소형 도형 장식: 원본 목재 블록/수관 메시를 재사용.
- 드롭 아이템: 원본 바위 조각/용기. 물/불/마법은 기존 셰이더를 사용.

게임 런타임
OpenGL의 기존 VBO 정점 캐시 방식에 맞춰 메시와 8개 걷기 포즈를 미리 구웠습니다.
실시간 골격 스키닝/애니메이션 블렌딩은 아직 구현하지 않았습니다.
원본 Blender의 점프/공격/회전/달리기는 Source에 보존되지만 게임 동작에 연결되지 않았습니다.
게임의 현재 공격 효과와 이동/전투 로직은 유지됩니다.
기존 Hero/Slime/Boar enum은 저장·전투 호환을 위해 유지되며 시각 모델만 교체했습니다.

빌드 시 Assets/Willowmere의 파일이 실행 파일 옆 Assets/Willowmere에 자동 복사됩니다.
실행 시 게임용 바이너리를 읽으며 Blender 설치는 필요하지 않습니다.
구형 모델 캐시는 버전 5로 갱신됩니다. 에셋 팩이 캐시보다 우선합니다.
원본 blend는 실행 폴더로 복사하지 않습니다.
파일 누락/손상은 조용히 구형 도형으로 대체하지 않고 초기화를 중단합니다.

검증: 73개 모델, 정점 범위/유효성/법선/체크섬/enum 대응, vcxproj XML 검사 통과.
게임 빌드와 실제 화면은 사용자 확인 대상으로 남겼습니다.


2026-10-22 그래픽 표현 개선
- 마을 배치, 이동, 충돌, 전투, NPC 행동은 변경하지 않음.
- 마을/사냥터 공통: 목재 결, 석재 줄눈과 이끼, 잎 색 변화, 석회벽 재질.
- 건물: 겹친 지붕 타일, 서까래, 기단 석재, 창살, 화분, 덩굴. 한 건물 메시로 합침.
- 자연물: 여러 잎 덩어리로 조합한 수관과 풍성한 풀잎 메시.
- 조명: 따뜻한 태양광과 차가운 환경광, 가장 가까운 등불/모닥불 최대 8개.
- 후처리: 깊이 기반 접촉 음영, HDR 블룸, 필믹 톤 매핑, 가장자리 완화.
- 물: 연속 수면, 물결 법선, 청록색, 하늘 색 반사와 햇빛/등불 반짝임.
- 물 반사는 절차적 하늘 표현이며, 실제 주변 건물의 반사나 레이트레이싱이 아님.
- 등불은 표면을 비추지만 개별 그림자를 생성하지 않음. 태양 그림자는 기존 PCF 사용.
- 성능 제한: 점광원 8개, 접촉 음영 12샘플. 실제 FPS는 게임 실행 후 확인 필요.
- Tools/enrich_willowmere.py: Blender 원본 디테일 생성 및 미리보기.
- Tools/export_willowmere.py: 원본을 게임용 meshes.bin으로 내보내기.
- 재질 식별자는 정점 UV.y의 -100 이하 값으로 저장. 일반 텍스처 UV와 분리.
검증: OpenGL 드라이버에서 World/Post 셰이더 컴파일 및 링크 통과.
게임 자체 빌드/실행은 하지 않음. 실제 화면 및 성능은 사용자 실행 확인 대상.


조경 개선 (2026-10-22)
- 이전 분리된 큐브 수관을 폐기하고 외곽 면만 가진 연속 계단형 수관으로 교체.
- 풀은 끝이 가늘고 휘어진 리본 잎으로 제작.
- 기존 주택에 석재 화단, 생울타리, 꽃, 뒤쪽 테라스와 낮은 계단을 통합.
- 5개 마을의 길/연못/주택/나무와 거리를 확보한 빈 공간에 소형 정원을 최대 12개씩 배치.
- 조명과 색감, 퀘스트 및 전투 규칙은 유지. 장식 높이 차이이며 이동 지형의 높이 시스템은 변경하지 않음.
- 수관과 정원은 합친 메시 사용. 새 Garden 모델 추가로 74개 모델을 내보냄.
- 재생성 순서: enrich_willowmere.py -> garden_willowmere.py -> export_willowmere.py.
- 게임 빌드/실행은 사용자 확인. Blender 원본 미리보기와 에셋 무결성 검증 수행.

계단형 지형 업데이트
독립 Garden 배치를 제거하고, 빈 공간에 넓은 계단형 잔디 언덕을 생성합니다.
길/주택/연못/퀘스트 지점은 낮게 유지하고 주변으로 완만하게 높아집니다.
각 계단 높이는 최대 0.18, 같은 높이 정보를 배우/주민/동물/수목 배치에도 사용합니다.
지형은 16x16 구역별 VBO로 한 번 업로드하며 씬 그래프로 컬링합니다.
조명/색감과 기존 집에 붙은 화단은 유지합니다. 사냥터 지형은 변경하지 않습니다.
셰이더 컴파일/링크 검증 통과. 게임 빌드와 이동/렌더링 결과는 사용자 확인 대상입니다.
