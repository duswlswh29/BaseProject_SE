# 마을 인구·전투 테스트

## 2026-10-14 지역 연결
기본 실행은 마을, --level1은 사냥터에서 시작한다. 실행 중 Tab으로 서로 이동한다.
지역별 위치와 몬스터/퀘스트 상태는 실행 중 메모리에 유지된다. 비활성 지역 AI는 정지한다.
플레이어 체력·레벨·경험치·화폐·아이템은 기존 Rpg::Stats 하나를 공유한다.
기존 level1-progress.dat를 시작 시 한 번 읽고 자동 저장/지역 전환/종료 시 저장한다.
마을에서 좌클릭·F·스페이스로 범위 공격, Q로 공용 회복약을 사용한다.
호숫가 돌 퀘스트 단계에서는 스페이스의 퀘스트 동작을 우선한다.
공격 연출은 아직 다르다: 마을은 근접 범위 마법, 사냥터는 기존 투사체다.
마을 R은 지역 테스트만 초기화하며 공유 플레이어 성장은 초기화하지 않는다.
아래 옛 테스트 수치/저장 설명보다 이 절을 우선한다.
모니터링 JSON은 현재 마을에서만 송신한다. 사냥터 체류 중에는 마지막 마을 기록이 오래된 데이터로 표시된다.
확인: 마을 처치 → Tab → 동일 레벨/체력/동전 확인 → Tab 복귀 → Q/상인 치유 → 종료 후 재실행.

## 외곽 환경 보강
기존 집 8채 외에 길 주변 비대칭 위치에 집 20채를 추가했다.
연못 4곳은 렌더링·이동 충돌·나무 배치·미니맵에 함께 반영한다.
집 입구에서 기존 도로까지 진입로를 연결하고 외곽 집 옆에 텃밭을 배치한다.
낮은 수풀과 작은 바위는 고정 시드의 불규칙 위치에 추가하며 이동을 막지 않는 장식이다.
지면은 화면 끝의 회색 바탕 노출을 줄이도록 확장했지만 플레이 경계는 동일하다.
사용자 확인: 외곽 집 진입로, 새 연못 충돌, 숲길 이동, 추가 소품의 화면 밀도와 프레임 시간.

## 실행
명령 인수를 비우고 Ctrl+F5로 실행하면 기본으로 마을에 들어간다.
기존 `--village`와 `--tutorial`도 마을로 들어간다. 기존 사냥터는 `--level1`로 실행한다.
빌드와 화면 확인은 사용자 담당이다.

## 범위
- 기존 주민 12명 + 추가 주민 20명 = 32명.
- 이동 경계 X ±28/Z ±26 → X ±56/Z ±52: 가로·세로 2배, 면적 4배.
- 기존 집·호수·퀘스트는 중앙에 보존하고 외곽 숲을 확장했다.
- 슬라임·멧돼지 합계 목표 64마리. 충돌과 간격을 검사하여 외곽에 생성한다.
- 처치 후 12초가 지나고 플레이어가 생성 지점에서 5 이상 떨어지면 재생성한다.
- 몬스터 추적은 발견 거리 6, 생성 지점으로부터 9 이내로 제한한다.
- 기존 Actor/SceneGraph를 사용하며 몬스터와 확장 숲의 나무는 ModelCache를 사용한다.

## 조작과 임시 수치
WASD 이동 / E 대화·거래·치유 / F 근접 범위 방어 마법 / 스페이스 기존 퀘스트 마법.
ESC 일시정지 / R 전체 테스트 초기화.
체력 100, 초기 동전 10. 상인: 동전 2로 체력 30 회복. 성직자: 무료 치유.
몬스터는 F 3회로 처치, 경험치 5와 동전 1 획득. 사망 시 마을에서 회복한다.
경비가 처치한 몬스터는 플레이어에게 보상을 지급하지 않는다.
산적·심술궂은 NPC는 F로 5초간 물러나게 할 수 있다. 중요 NPC는 죽지 않는다.
테스트 체력·경험치·동전은 메모리에만 있으며 기존 레벨 1 저장 파일을 변경하지 않는다.
현재 경험치 표시는 전투 테스트용이며 이 모드에서는 레벨업/스탯 배분을 추가하지 않았다.

## Story와 행동의 대응
Story는 Markdown 문법의 확장자 없는 파일이다. 문서에는 개별 주민 20명의 AI 명세가 없다.
아래 동작은 문서의 역할을 참고해 이번 요청에 맞게 추가한 테스트 패턴이다.
문서 전체 메인 퀘스트/역사 공개 순서/후반 사건을 구현한 것은 아니다.

| 주민 | 적용 패턴 |
|---|---|
| 미라 교수 | 기존 퀘스트를 위해 고정 위치 유지 |
| 제빵사 핍, 약초상 세라, 상인 마르 | 상점 대기·E 회복 거래 |
| 학생 리오 | 공부 구역 왕복 |
| 정원사 페른, 낚시꾼 노리, 대장장이 로엔, 목수 오린 | 작업 구역 배회 |
| 배달부 베아 | 배회·체력이 낮은 플레이어 근처로 접근 |
| 견습생 루나 | 장치 실험 구역 순회 |
| 순찰대원 도윤 | 순찰·주변 몬스터 대응 |
| 모범생 동료, 도서관 견습생 | 작은 공부 구역 왕복·기록 비교 대화 |
| 사고뭉치 동료, 장치 수리 견습생 | 실험 구역 원형 이동·실험/수리 대화 |
| 마법생물학 교수, 왕국 조사관 | 조사 구역 순회·관찰/증거 중심 대화 |
| 학교장, 경비대원, 숲 경비대원 | 순찰·발견한 몬스터에게 접근해 공격 |
| 식료품 상인, 약초 상인 | 고정 상점·E 회복 거래 |
| 여행 성직자, 호수 성직자 | 배회·주변 부상자 주기적 치유·E 완전 회복 |
| 친절한 농부, 선한 여행자, 친절한 길잡이 | 배회·부상 플레이어에게 접근 |
| 산적 정찰병, 산적 두목 | 영역 배회·근거리 추적·안전 구역 밖 공격·피격 시 후퇴 |
| 심술궂은 주민, 수상한 떠돌이 | 가까이 따라오다가 물러남·불친절한 대화·피격 시 후퇴 |

성격별 행동은 단순 상태/거리 기반이다. 실제 공부·수리 퍼즐, 정식 증거 시스템,
낮밤 시간표, 주민 관계 저장, 도둑질, 상점 인벤토리, 신규 메인 퀘스트는 이번 구현 밖이다.

## 확인
1. 주민 32명이 있고 이동 중 E로 가장 가까운 인물과 대화하는지 확인한다.
2. 상인 거래·성직자 치유·경비와 산적 행동을 확인한다.
3. 동서남북 외곽에서 몬스터를 찾고 F로 처치한 뒤 재생성을 확인한다.
4. 체력 소진 시 마을 복귀, 일시정지, R 초기화를 확인한다.
5. 기존 씨앗·호숫가 돌 퀘스트가 계속 진행되는지 확인한다.
6. JSONL의 village.population_update / resident_ai / monster_ai 및
   village.residents / monsters_total / monsters_alive를 확인한다.
